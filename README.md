# Bot City

Static site: the Bot City night grid, plus Holo Arena (local or online two-player).

- [index.html](index.html) — Bot City
- [arena.html](arena.html) — Holo Arena
- [drumhero.html](drumhero.html) — Drum Hero

Published from the repository root:

- https://jaypowersmusic.github.io/bot-city-plug-music-/
- https://jaypowersmusic.github.io/bot-city-plug-music-/arena.html
- https://jaypowersmusic.github.io/bot-city-plug-music-/drumhero.html
